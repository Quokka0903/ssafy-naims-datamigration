## 3. 각 요청에 대한 Claude의 핵심 응답/설계 판단

### R05 — 소스코드 구조 파악

- 파싱 완성, DB INSERT 전부 TODO 상태로 확인
- 기존 RootPath는 모두 `public string RootPath { get; }` 읽기 전용 const 문자열

### R06 — 경로 오분석 정정
- 경로명 한글이 터미널에서 깨져 보인 것. `Test-Path` 결과 `True`. 이전 "경로 불일치" 지적은 오류였음.

### R07 — 경로 선택 리팩토링 설계 판단
- `Microsoft.Win32.OpenFolderDialog` (.NET 8 WPF 내장) 사용
- `Model/Common.cs`: `const string` → `static string { get; set; }` + 기본값 `D:\MSU\...`
- 각 ViewModel: `_rootPath` backing field + `SelectRootPathCommand` 추가
- `NarrowBandTabViewModel`: 경로 변경 후 `ScanNbFolders()` 자동 재실행
- 바인딩 오류 선제 수정: `Sd.Files` → `Files`, `NbGroup.Files` → `Files`

### R08 — TwoWay 바인딩 오류
- 원인: DataGrid `IsReadOnly="False"` 상태에서 셀 더블클릭 → WPF 편집 모드 진입 → get-only 속성에 TwoWay 쓰기 시도
- 수정: 3개 DataGrid의 모든 `DataGridTextColumn`에 `IsReadOnly="True"` 추가 (CheckBox 컬럼만 편집 가능 유지)

### R09 — TmpFileReader 수정 (wpftmp 빌드 실패 해결 포함)
- wpftmp 빌드 실패 근본 원인: Edit 툴이 ASCII `"` 대신 Unicode curly quote `"` (U+201C/U+201D) 삽입
- Python 바이너리 치환으로 10곳 수정: `replace(b'\xe2\x80\x9c', b'"').replace(b'\xe2\x80\x9d', b'"')`
- 추가 수정:
  - `$"..."` 보간 문자열 → 연결 문자열 (`+`) 전환
  - `TryRead<T> where T:struct` → 구체적 오버로드 3개 (int, float, double)
  - `init` → `set` (replace_all)
  - `new()` → `new List<TrTmpSegmentResult>()`
- SdParser.cs: `StartFreq = s.StartFreq` → `StartFreq = 0` (제거된 필드 참조 수정)
